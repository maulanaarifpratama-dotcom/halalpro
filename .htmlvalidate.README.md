# Kenapa `no-inline-style` dimatikan

Aturan itu ada untuk mencegah styling presentasional bocor ke markup. Setiap
atribut `style` yang tersisa di `index.html` **hanya** berisi custom property —
sebagian besar `--i`, indeks stagger per elemen yang dipakai
`transition-delay: calc(var(--i) * 60ms)`.

Nilai itu adalah *data per instance*, bukan presentasi: ia tidak bisa hidup di
stylesheet tanpa menulis puluhan selector `nth-child` yang rapuh terhadap
perubahan urutan DOM.

Pengecualian ini dijaga, bukan diasumsikan. `npm run validate` gagal kalau ada
atribut `style` yang mengandung properti CSS sungguhan, jadi aturan ini tidak
bisa dipakai diam-diam untuk menyelundupkan styling ke markup.
